# Werkzeugdeck · Historisches Archiv

**Die aktuelle Entwicklung liegt vollständig in [FalkBornmann/Werkzeugdeck](https://github.com/FalkBornmann/Werkzeugdeck).**

[Werkzeugdeck öffnen](https://werkzeugdeck.pages.dev/) · [Alle Tools und Themenordner](https://github.com/FalkBornmann/Werkzeugdeck#aufbau-und-mitarbeit)

Seit dem 28. November 2026 liegen Website, neun Tools, Fachtheorie und gemeinsame Projektregeln in einem einzigen öffentlichen Repository des persönlichen Kontos. Neue Anwendungen werden dort als Themenordner ergänzt.

Diese kostenlose Organisation bleibt ausschließlich zur Erhaltung der bisherigen Tool-Repositories, Historien und Links bestehen. Ihre Tool-Repositories sind archiviert. GitHub Actions ist in allen verbleibenden Repositories deaktiviert. Hier findet keine weitere Entwicklung statt.
