# Werkzeugdeck Organisationsprofil

- Diese Organisation heißt `Werkzeugdeck`. Alle neuen öffentlichen Werkzeugdeck-Tool-Repositories werden hier angelegt. Kein persönliches Ersatz-Repository erstellen.
- Zentrale Projektregeln und Konfiguration: https://github.com/Werkzeugdeck/website/blob/main/AGENTS.md und `github-organization.json` im selben Repository.
- Neue Tools nach Fachgebiet in `profile/README.md` verlinken. Öffentliche Tool-Adressen bleiben `/tools/<id>/`.
- Microsoft Edge weder verwenden noch anfragen.

- Kostenregel: Werkzeugdeck muss ohne kostenpflichtige Dienste betrieben werden; zulässiges Zusatzbudget: 0 USD. GitHub Free beibehalten. Keine Zahlungsmethode hinterlegen, Budgets erhöhen, kostenpflichtigen Abonnements oder Testangeboten mit späterer Zahlung zustimmen oder bezahlte Runner, Codespaces, Speicher, KI-/API-Kontingente oder Marketplace-Dienste aktivieren. Vorhandene 0-Dollar-Budgets mit Nutzungssperre erhalten. Nur nachweislich kostenlose Funktionen innerhalb ihrer Freigrenzen verwenden; bei ausgeschöpften Kontingenten stoppen oder lokal weiterarbeiten. Standard-GitHub-Actions-Runner für öffentliche Repositories sind zulässig; keine größeren Runner. CI-Artefakte vermeiden und notwendige Fehlerartefakte nur 1 Tag aufbewahren. Diese Regel in jedes neue Tool-Repository übernehmen. Details und Prüfstand: https://github.com/Werkzeugdeck/website/blob/main/docs/GITHUB-ORGANISATION.md.
